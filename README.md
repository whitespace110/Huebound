# Huebound

A small 8-bit inspired color-based 2D platformer made with **LÖVE2D** and Lua.

In Huebound, the player's current color determines which platforms are visible and solid. Switch colors, navigate through the levels, and reach the goal as quickly as possible.


## Controls

| Key      | Action            |
| -------- | ----------------- |
| `A / D`  | Move              |
| `W`      | Jump              |
| `R`      | Reset             |
| `Escape` | Pause             |
| `F3`     | Toggle debug mode |
| `F11`    | Toggle fullscreen |

## Built With

* **[LÖVE](https://love2d.org/)** — 2D game framework for Lua.
* **[Windfield](https://github.com/a327ex/windfield)** — Physics and collision handling for LÖVE.
* **[STI (Simple Tiled Implementation)](https://github.com/bjornbytes/sti)** — Loading and rendering levels created with Tiled.
* **[HUMP](https://github.com/vrld/hump)** — Used for the camera system.
* **[anim8](https://github.com/kikito/anim8)** — Sprite animation library for LÖVE.
* **[TSerial](https://github.com/MikuAuahDark/TSerial)** — Serialization of save data.

## Tools

* **[Tiled](https://www.mapeditor.org/)** — Level/map creation
* **[LibreSprite](https://libresprite.github.io/)** — Pixel-art and sprite creation
